🎨 主题配色（三套 · 京阿尼柔光水彩调）

色相沿用三张参考照片，但整体按京阿尼式水彩赛璐璐重调：去浊提纯 → 降饱和提明度（更柔）→ 暗部/投影改用彩度阴影 → 底色加空气感渐变与顶部柔光。详见下方「京阿尼柔光七原则」。本轮唯一目标是「更柔」：主色 S 普遍 −15~−20、L +5~+10，投影由死黑改彩色柔影，圆角整体 +2~4。

🎯 配色应用规则（主色 × 辅助色 × 中性色）

原则：照片怎么用色，界面就怎么用色——大面积底色铺陈、中等块面交给主色、小面积高光只做点睛。

  • 中性色 ≈ 60%（页面的骨架）：BG 铺底、Surface 承卡片、Border 做分割、Text 压文字。对应照片里的墙面与阴影，永远不抢戏
  • 主色 ≈ 30%（品牌的脸）：主按钮底、导航选中态、Toggle 开启、Logo 底色、进度条、Tag 文字、焦点环。对应照片里那块大面积的蓝／粉／服装色
  • 辅助色 ≈ 10%（情绪的焦点）：Logo 连接线、成功 Toast 图标、空状态插画焦点、图表高亮。对应照片里的橙窗框、落日暖光——只点缀，绝不铺面
  • 语义色 ≤ 5%：Success / Danger 只在状态出现；用量类进度条超过 80% 自动转 Danger

🇯🇵 京阿尼柔光七原则（本次调色的依据）

  • ① 去浊提纯：拒绝灰褐、土黄、橄榄这类「写实照片的中间调」，每个色都要有明确色相。旧值 → 新值示例：#64798C 水泥灰 → #6B85A2 靛蓝灰；#5C5952 砖地灰 → #63718C 蓝灰；#7FA86B 橄榄绿 → #86D9B4 若叶绿
  • ② 彩度阴影（赛璐璐核心）：暗部不是灰色，而是底色的高饱和低明度版。所以 Text 不用中性灰，默认主题走深蓝影 #3E5670、A 走深蓝黑 #3E4A63、B 走深紫影 #63495E——阴影里能读出主题色相
  • ③ 高光留白：亮部保持纯白 #FFFFFF 不掺灰，Surface / Logo 前景 / 上传箭头一律纯白，模拟动画里的高光块
  • ④ 空气透视：底色高明度、低饱和、偏青，营造日本动画背景的透明空气感；本轮再叠一层 --c-bg → --c-bg-2 的浅渐变 + 顶部白雾柔光（逆光空气）。三套 BG 分别为 #EDF4FA（偏青）/ #EDF2F9（偏青）/ #FAF1F4（偏粉）
  • ⑤ 亮色分离：主色要守按钮白字对比度（≥3:1），想更“动漫”的亮蓝亮粉另立 --c-primary-vivid，只给插画/缩略图/装饰用，不铺按钮底
  • ⑥ 柔化降饱和（本轮新增，京阿尼的“水彩感”来源）：主色 S 压到 45~55%、L 提到 50~65%（旧值普遍 S 65~75 / L 45~55）。柔 ≠ 灰——降饱和的同时必须保住色相与明度，否则就退回“去浊”要消灭的水泥灰
  • ⑦ 彩色柔影 + 圆润边界（本轮新增）：投影弃用 rgba(0,0,0,.06) 的死黑，改用 --c-shadow（主题色的低饱和暗相）+ 大 blur（8~24px），卡片像浮在空气里；同时圆角整体 +2~4、描边再淡一档，边界不割手

照片用色 → 界面角色（取色映射）

  • 默认「晴空蓝 × 夕照金」：雾蓝纱帘/墙 60% → 骨架（偏青的晨光白 #EDF4FA）；丹宁蓝外套 28% → 主色（提纯为晴空蓝 #4E93C0）；落日暖光 7% → 辅助色（去土味的夕照金 #FFC978）；炭黑暗部 5% → 文字（彩度阴影 #3E5670）
  • 变体 A「群青 × 夕橙」：墙面明度 62% → 骨架（去黄相，用青光白 #EDF2F9）；群青雨棚 24% → 主色（提亮为群青 #6484CE）；橙窗框 8% → 辅助色（夕橙 #FFA978，只做强调线与边框）；黑裙/灰砖地 6% → 文字与中性（深蓝黑 #3E4A63 / 蓝灰 #63718C）
  • 变体 B「樱粉 × 若叶」：暖白墙面 65% → 骨架（去黄相，转樱白 #FAF1F4）；粉色门头与绣球 22% → 主色（提饱和为玫樱 #D37493）；花园绿植 10% → 辅助色兼 Success（若叶 #86D9B4）；暖褐阴影 3% → 文字（深紫影 #63495E）

中性底色的降脏三原则

  • 只借明度，不借色相：照片墙色带黄相，直接铺大面积必脏；取它的明度（约 95% 亮度），色相改用主色的同族浅色或纯中性灰
  • 通道差按色相分档：暖相（R>B，易发黄发灰）必须 ≤ 6；冷相（B>R，如青光白、晨光白）可放宽到 12，读起来仍是干净的白而非脏灰。当前三套底色：#EDF4FA（差 12，冷）/ #EDF2F9（差 12，冷）/ #FAF1F4（差 11，粉相）
  • 与白卡保持 10+ 亮度差：底色与 Surface 纯白至少差 10 个亮度级，否则卡片浮不起来、界面糊成一片；靠描边 + shadow-1 再补一层。反例：#F8F6F5 与白只差 7，整屏发糊；本轮动漫化一度想用更亮的 #F5FAFF（只差 5），已按此条驳回并压到 #EDF4FA（差 10）

组件级分工（不许串岗）

  • 必须主色：主按钮底、导航选中、Toggle on、Logo 底、Tag、进度条、Focus 环
  • 可以辅助色：Logo 折角/连接线、Toast 图标、空状态插画焦点、图表高亮、hover 微强调
  • 禁止辅助色：正文文字、可点击文字（会与主色语义混淆）、大面积按钮底、卡片底色
  • 每屏上限：辅助色在同屏出现不超过 3 处，主色不超过 5 个主要块面

已落地示例：顶栏容量进度条（主色填充，超 80% 转 Danger）、上传成功 Toast（夕照金图标点睛）——拖个文件到放置区即可看到。

✨ Logo 与状态动效（Discord 式）

  • 造型：44×44 squircle（圆角 ≈30%，Discord 同款比例）；「层叠图片 + 外链」——前白后蓝两张相片错位层叠，一道琥珀斜线贯穿相连，正好是图床的核心流程：上传图片 → 拿到外链
  • 配色与主题绑定（关键约束）：Logo 底色只能从当前主题的色系里取，禁止跨主题混用（B 主题下不能用晴空蓝）。每套主题固定给三个候选位：① 主色同族（最稳，与界面一体）· ② 彩度阴影色（最克制，＝该主题暗部的紫/蓝紫，非中性灰）· ③ 辅助色点睛（辨识度最高，但底面积小，不违反辅助色不铺面的法则）

🎯 Logo 主题化配色（令牌驱动 · 交付实现要求）

目标：默认主题 Logo 底版 #4E93C0、A 主题 #6484CE、B 主题 #D37493。三个色值全部抽成 CSS 变量，切主题时靠变量覆盖自动生效，组件内零硬编码。顶栏切换主题即可看到左上角 Logo 自动换色。

1. 令牌表（Logo 专属 · 组件级）

令牌默认·晴空蓝A·群青×夕橙B·樱粉×若叶作用部位
--logo-bg#4E93C0#6484CE#D37493底版（squircle 方块）
--logo-ink#FFFFFF#FFFFFF#FFFFFF前层相片、上传箭头
--logo-accent#A9DDF3#BFD5F7#F8C9DC后层相片
--logo-line#FFC978#FFA978#FFFFFF连接线 + 扫描线
--logo-ring78,147,192100,132,206211,116,147呼吸光环 / 投影（RGB 三元组，配 rgba 用）
--logo-bg-v2/-v3#8A7EB4 / #FFC978#7975AA / #FFA978#6E5468 / #86D9B4主题内候选位 ②③（由 data-logo 提升为生效值）
  • 底色即各主题主色（晴空蓝 / 群青 / 玫樱），与界面主色同源，保证「Logo 与界面是一套色」；动漫化后饱和度提高，小尺寸更抓眼
  • --logo-ink 三套统一纯白：前景图形在所有底色上都保持最大对比，且符合赛璐璐的「高光留白」——不做逐主题调色，避免某主题下前景发灰
  • --logo-line 必须跟着底版走：粉底上暖色线会糊，故 B 转纯白高光；A 用夕橙做蓝橙对撞；金底（D3）反过来用深棕 #8A6A3A 才看得见

2. 变量命名规则

  • 全局调色板：--c-{角色} —— 如 --c-primary / --c-accent / --c-bg，跨组件通用
  • 组件级令牌：--{组件}-{部位} —— 如 --logo-bg / --logo-line，只在本组件内消费
  • 组件内候选位：--{组件}-{部位}-v{n} —— 如 --logo-bg-v2，n 从 2 起（1 即生效值本身，不另设）
  • 选择器分层：:root 声明默认 → body[data-theme="xxx"] 覆盖主题 → body[data-theme][data-logo="v2"] 覆盖候选位（特异性 0,2,1 > 0,1,1，保证候选位能盖过主题）
  • 主题名用小写单词：klein / cream，与 data-theme 属性值一一对应，禁止用中文或驼峰

3. 回退机制（三道防线，主题未匹配 / 加载失败也不会崩）

  • ① :root 兜底：--logo-bg:#4E93C0 写在 :root，任何主题都继承得到，主题块缺失时自动用默认值
  • ② 消费处双保险：组件里统一写 var(--logo-bg, #4E93C0)，即使变量被意外清空也回退到默认色，不会变黑或透明
  • ③ JS 白名单校验：THEME_WHITELIST=["", "klein", "cream"]，传入未登记的主题名（拼写错误 / 配置加载失败 / 异步未就绪）一律回退默认主题；候选位下标越界同样回退到 ①
  • ④ 宿主不在 body 上：若主题挂在 <html> 或某个容器上，把 body[data-theme] 换成对应宿主即可，令牌与消费处无需改动

4. 若 Logo 以图片资源引入，如何按主题切换

方案做法适用
A 内联 SVG + 变量（推荐）图形不写色值，全部 fill:var(--logo-*)首选，一份资源自适应所有主题
B 单色图标 + maskmask-image 裁形 + background-color:var(--logo-bg)已有单色 PNG/SVG，想任意换色
C 多版本位图--logo-img 存 URL，主题块覆盖必须是彩色位图、各主题造型不同
D SVG symbol + currentColorSVG 内写 fill="currentColor"，父级设 color:var(--logo-bg)图标库统一管理
/* 方案 B：一份单色资源，主题化换色（推荐给位图） */
.logo-mask{
  width:44px; height:44px;
  background-color:var(--logo-bg, #4E93C0);
  -webkit-mask:url("logo-shape.svg") center / contain no-repeat;
          mask:url("logo-shape.svg") center / contain no-repeat;
}

/* 方案 C：彩色多版本，按主题换 URL（末位为回退资源） */
:root{ --logo-img:url("/assets/logo-default.png") }
body[data-theme="klein"]{ --logo-img:url("/assets/logo-klein.png") }
body[data-theme="cream"]{ --logo-img:url("/assets/logo-cream.png") }
.logo-img{
  width:44px; height:44px;
  background-image:var(--logo-img, url("/assets/logo-default.png"));
  background-size:contain; background-repeat:no-repeat;
}

/* 方案 D：SVG symbol + currentColor */
.logo-sprite{ color:var(--logo-bg, #4E93C0) }   /* SVG 内部 fill="currentColor" */
  • 注意：<picture> / srcset 只能响应媒体查询（如 prefers-color-scheme），无法响应 data-theme。若必须用 <img> 标签，改用 JS 按主题赋值并保留回退：
const LOGO_SRC = { "":"/assets/logo-default.svg",
                   klein:"/assets/logo-klein.svg",
                   cream:"/assets/logo-cream.svg" };
function applyLogoImg(theme){
  // 未匹配的主题（含 undefined / 拼写错误）→ 回退默认版本
  img.src = LOGO_SRC[theme] || LOGO_SRC[""];
  img.alt = "图床工具 Logo";
}

5. 新增主题时的扩展方式

  • Step 1　在 :root 同级的主题区新增一段 body[data-theme="{新主题名}"]，覆盖 --c-*（界面）与 --logo-*（Logo）两组令牌
  • Step 2　至少提供 --logo-bg / --logo-accent / --logo-line / --logo-ring 四个生效值；--logo-ink 沿用纯白，除非底版过浅需要转深色
  • Step 3　如需主题内候选位，追加 --logo-bg-v2/-v3（及其 accent / line / ring），body[data-logo="v2"] 的提升规则无需改动
  • Step 4　把新主题名加入 JS 的 THEME_WHITELIST 与 LOGO_VARIANTS（只填 label / note 文案，不填色值）
  • Step 5　组件、SVG 造型、动效代码一律不改——这是令牌化的验收标准：新增主题的行数应 ≈ 15 行 CSS + 3 行 JS
/* Step 1–3 模板：复制后改色值即可 */
body[data-theme="forest"]{              /* ← 新主题名，小写单词 */
  --c-primary:#2F6B4F; --c-accent:#C9A227; /* 界面令牌 */
  --logo-bg:#2F6B4F; --logo-accent:#A8CBB4; --logo-line:#C9A227; --logo-ring:47,107,79;
  --logo-bg-v2:#4A423B; --logo-accent-v2:#B8AEA3; --logo-line-v2:#C9A227; --logo-ring-v2:74,66,59;
}                                        /* v3 可选，不给即无候选位③ */
/* Step 4：THEME_WHITELIST.push("forest"); LOGO_VARIANTS.forest={...}; */
  • 验收：切到新主题后 Logo 底版 = 新 --logo-bg，且扫描线、光环、投影、上传箭头全部同步换色（本页点 Logo 可预览动效）
